# Demo Video Script

> **Target length:** 2–3 minutes  
> **Format:** Screen recording with voiceover narration  
> Each `[SHOW]` cue tells you what should be on screen.

---

## Opening — The Problem (0:00–0:18)

> *"Hi, we're team **Name Yad Nahi**, and this is **ThreatIntel Correlator** — our submission for the IBM Bob AI Hackathon, Challenge D2.*
>
> *The problem: SOC analysts receive hundreds of security alerts every single shift. Most are noise — duplicates, false positives, low-signal events. Finding the real, critical threats buried in that noise takes hours of manual work. That delay gives attackers time to move laterally and do damage.*
>
> *We built a tool that automates that triage — in seconds."*

**[SHOW: Dashboard home page — clean state with KPI cards at zero]**

---

## Data Ingestion (0:18–0:40)

> *"Let me show you how it works. I'll go to the Upload page and click **Load Sample Data**. This simulates ingesting a realistic batch of threat alerts from a security tool.*
>
> *In the background our pipeline instantly fires: it normalises the raw data, runs false-positive detection using six deterministic rules, computes a transparent risk score from zero to one hundred for every alert, maps each alert to a MITRE ATT&CK technique, and then groups related alerts into incidents.*
>
> *Back on the dashboard — look at those KPI cards. Alerts ingested. Incidents created. High-priority flags. All populated in under a second."*

**[SHOW: Click "Upload" in sidebar → "Load Sample Data" button → watch dashboard KPI cards populate]**

---

## Explainable Risk Scoring (0:40–1:00)

> *"Let's look at the Alerts view. Every alert shows a risk score. And crucially — that score is **fully explainable**. I can expand the breakdown and see exactly how the number was computed: severity rating, event type weight, destination IP sensitivity, how many times this source IP has appeared, and keyword signals in the description.*
>
> *No black box. A judge or analyst can verify every number by inspection."*

**[SHOW: Alerts table → expand/hover a score breakdown to show the five factor tooltip]**

---

## Incident Correlation + watsonx BLUF (1:00–1:35)

> *"Now the most powerful view — Incidents. These are correlated groups of related alerts. Instead of reviewing fifty individual alerts, the analyst sees a handful of incidents, each representing a coherent attack pattern.*
>
> *I'll click into a HIGH-priority incident. At the top, the **BLUF summary** — Bottom Line Up Front. This is a military-style commander briefing generated by **IBM Granite on watsonx.ai**. In four sentences it tells you what happened, which MITRE techniques were used, and what action to take.*
>
> *No API key? The app uses a deterministic template fallback that produces the same structure — so the demo is fully functional offline. The badge here shows which path was taken."*

**[SHOW: Incidents list page → click a HIGH incident → Incident Detail page showing BLUF summary, MITRE tags, risk score, contributing alerts list]**

---

## MITRE ATT&CK Map (1:35–1:50)

> *"The MITRE Map gives a bird's-eye view of the entire attack surface — which ATT&CK techniques are being seen and how frequently. A commander can immediately spot whether attackers are focused on Initial Access, Command & Control, or Exfiltration.*
>
> *All technique mapping runs locally against a curated lookup table. No external service required."*

**[SHOW: MITRE Map page — heatmap of techniques with counts]**

---

## Closing (1:50–2:00)

> *"ThreatIntel Correlator gives SOC analysts one clear, prioritised view of what's actually happening — with explainable scores, automated correlation, and IBM Granite-powered briefings. Thank you."*

**[SHOW: Dashboard summary page — final clean shot]**

## Recording Tips

- Record at **1080p**, browser full-screen
- Zoom into key UI elements (score breakdowns, BLUF text) so they are readable
- Free tools: OBS Studio (Windows/Mac/Linux) or Windows Game Bar (`Win + G`)
- Speak clearly — the voiceover is the most important part
- Do one dry run before the final recording
